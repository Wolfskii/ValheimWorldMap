# ValheimWorldMap brand assets

- `valheimworldmap-icon*.png` and `favicon.ico`: the compass-rose shield icon at 1024, 512, 192, 64 and 32 px. The same artwork is embedded in the live map (`src/ValheimWorldMap/LiveMap/web/`) and the Thunderstore package (`tools/release/thunderstore/icon.png`).
- `valheimworldmap-mark.svg`: the compass mark as a currentColor vector, the same artwork the live map's sidebar renders inline. Use it wherever the icon has to sit on an arbitrary background.
